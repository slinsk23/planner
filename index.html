One-time Google setup (about 10 minutes)
  1. Go to console.cloud.google.com and create a project (any name, e.g. "Planner").
  2. Open APIs & Services → Library and enable Google Calendar API and Google Tasks API.
  3. Open Google Auth Platform (or OAuth consent screen), choose External, fill in the app name and your email. Under Audience → Test users, add your own Gmail address.
  4. Open Clients (or Credentials) → Create client → type Web application. Under Authorized JavaScript origins, add the address this page runs from:
  5. Copy the Client ID, paste it above, and press Connect Google. Google will warn that the app isn't verified; choose Continue, since it's your own app.

Google sign-in doesn't work when the file is opened by double-clicking (a file:// address). Run it from GitHub Pages or a local server instead; see the instructions that came with the file.
